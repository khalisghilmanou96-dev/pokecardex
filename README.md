# PokéCardDex — TCGdex direct

Version corrigée pour GitHub Pages :

- fonction « Carte au hasard » supprimée du frontend et du JavaScript ;
- aucun asset local ;
- plus de dépendance à Pokémon TCG API ;
- connexion directe à TCGdex en français ;
- accueil : `https://api.tcgdex.net/v2/fr/cards` ;
- recherche par nom directement via TCGdex ;
- fiche détaillée chargée depuis `/cards/{id}` ;
- images servies directement par le CDN TCGdex.
