# PokéCardDex — connexion API directe

Version basée sur le fichier fourni.

- aucun dossier `assets`
- aucun catalogue de cartes local
- accueil chargé directement depuis `https://api.pokemontcg.io/v2/cards`
- recherche directement via Pokémon TCG API
- images récupérées depuis les URLs renvoyées par l'API
- le bouton aléatoire choisit parmi les cartes déjà reçues de l'API, sans second appel réseau
- compatible GitHub Pages
